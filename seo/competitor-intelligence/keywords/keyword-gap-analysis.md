## 8. Recommended page build order (from this gap analysis)

1. `/auto-caption-generator` — tool landing page (India + global; §2 highest density of small-tool competition, exact product match).
2. `/animated-captions` + 150-look styles gallery — one build serves two clusters (§2, §5, §7).
3. `/subtitle-generator` — free SRT/VTT tool page (§2, §6 free-SRT long-tail).
4. `/hinglish-captions` and `/hindi-subtitles` — per-language pages (§3, §6; proven structure, weakest global competition).
5. How-to guides: "How to add captions to a video (free, in browser)" and "How to add Hindi captions to a video" (§5 weak results, §7).
6. `/ai-subtitle-generator` — tool page; hardest SERP, build after 1–5 prove the template (§2).
7. Comparison pages vs CapsAI / CapCut / VEED / Clipchamp (§7) and roundup outreach (§3 Gadgets Now row).
8. Do NOT build pages for bare "AI caption generator" or "online caption generator" — target the video-qualified variants only (§4).
