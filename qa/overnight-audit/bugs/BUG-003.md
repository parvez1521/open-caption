# BUG-003 — `effectivePlanId` fail-open: unparseable or null expiry reads as paid

- **Severity:** P2
- **File:** `packages/shared/src/plans.ts:52-54`
- **Also:** `packages/shared/src/plans.test.ts:61` (test asserts the fail-open behaviour)

## Expected

A paid plan grants access only while it has a valid, unexpired `plan_expires_at`. A corrupt, unparseable, or missing expiry must read as Free (fail closed), never as paid.

## Actual (code behaviour)

```ts
export const effectivePlanId = (plan, expiresAt, now = new Date()): PlanId => {
  const id = planIdFor(plan);
  if (id === "free" || !expiresAt) return id;
  const end = expiresAt instanceof Date ? expiresAt : new Date(expiresAt);
  return Number.isFinite(end.getTime()) && end.getTime() <= now.getTime() ? "free" : id;
};
```

Two fail-open paths: (1) `!expiresAt` returns the paid id, so a paid row with `plan_expires_at = NULL` never expires; (2) an unparseable date string makes `end.getTime()` NaN, `Number.isFinite(NaN)` is false, so the ternary returns the paid id. The unit test locks this in: `plans.test.ts:61` asserts `effectivePlanId("growth", "not-a-date", now)` is `"growth"`. Every plan check in the app (upload caps, project count, billing page) flows through this function.

## Evidence

- `packages/shared/src/plans.ts:52` — `if (id === "free" || !expiresAt) return id;`
- `packages/shared/src/plans.ts:54` — `Number.isFinite(end.getTime()) && ... ? "free" : id;`
- `packages/shared/src/plans.test.ts:61` — `expect(effectivePlanId("growth", "not-a-date", now)).toBe("growth");`

## Root cause

The expiry check is written as "prove it expired to downgrade" instead of "prove it is still valid to keep the tier". The null case is treated as "no expiry" rather than "no proof of payment".

## Recommended fix

Fail closed: return `"free"` when a non-free plan has a missing or unparseable expiry. Update the test to assert `effectivePlanId("growth", "not-a-date")` is `"free"` and `effectivePlanId("growth", null)` is `"free"`. (Free plans are unaffected — they never expire.)
