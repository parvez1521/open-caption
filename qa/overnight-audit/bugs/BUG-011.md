# BUG-011 — Studio axe violations: timeline handles, trim sliders, tablist, landmarks

- **Severity:** P3 (2 critical, 1 serious, 4 moderate — all static markup)
- **Feature:** Studio editor
- **Route:** `/projects/[id]`
- **Tool:** axe-core 4.12.1, local dev
- **Files:** `apps/frontend/src/features/studio/StudioPage.tsx`, `apps/frontend/src/features/studio/Timeline.tsx`

## Findings (axe-core, Studio with a captioned project)
1. **`landmark-one-main` + `region` + `skip-link` — MODERATE.** `/projects/[id]`
   renders `StudioPage` directly with no `<main>`; the global skip link
   (`#main-content`) pointed at nothing.
2. **`page-has-heading-one` — MODERATE.** No h1 on the Studio page.
3. **`aria-prohibited-attr` — SERIOUS, 52 nodes.** Timeline word edge handles are
   `<span aria-label="Move start/end of <word>">` — `aria-label` is prohibited
   on a generic span. (26 words × 2 handles.)
4. **`aria-required-attr` — CRITICAL, 2 nodes.** Video trim handles are
   `<span role="slider">` with no `aria-valuenow` (slider requires it).
5. **`aria-required-children` — CRITICAL, 1 node.** The "Right panel tabs"
   `tablist` contained a third child — the "Collapse right panel" button —
   which is not a tab.
6. **`region` — MODERATE, 1 node (REMAINS, accepted).** The skip link itself sits
   outside any landmark. That is the conventional skip-link position; not a defect.

## Evidence
- `qa/overnight-audit/evidence/axe-studio-detail.json` (full node HTML)
- `qa/overnight-audit/evidence/axe-verify.json` (post-fix re-run)

## Fix applied (2026-11-14 ~06:15 IST, this branch)
1. All three `StudioPage` return sites: root `<div className="studio ...">` →
   `<main id="main-content" className="studio ...">`. (Fixes 1 + skip-link target.)
   The loading `StudioSkeleton` root and the `FullScreen` fallback got the same
   treatment, so the landmark exists from first paint.
2. Screen-reader-only `<h1>` with the project title next to the rename button.
   No visual change. (Fixes 2.)
3. Word + overlay edge handles: `aria-label` → `title` (same text, native tooltip,
   no invalid ARIA). (Fixes 3.)
4. Trim sliders: `aria-valuenow` + `aria-valuemin={0}` + `aria-valuemax={total}` +
   `aria-valuetext` (human time). (Fixes 4.)
5. Tablist restructured: the tablist div now holds only the tab buttons; the
   Collapse button is a sibling in the same flex row. No visual change. (Fixes 5.)

## Regression test
Re-run axe on `/projects/[id]` after the fix: only `region` (skip link, accepted)
should remain. No unit test added — these are static-markup rules best verified
